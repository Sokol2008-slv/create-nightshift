
# Грабли «Вахты» — копилка (Георгий, 29.09: «все такие ошибки сохраняй, это будет что-то типа скила»)

**Правило работы:** игрок сообщил о непонятке → (1) найди строку ниже и ответь по ней; (2) если это недосмотр
сборки — исправь в паке (рецепт/подсказка JEI/квест), (3) ДОПИШИ сюда новую строку и в копию репо
`~/projects/create-nightshift/docs/VAHTA-GOTCHAS.md` (одинаковый текст, коммит [claude]).

Репо: `~/projects/create-nightshift` (main = прод, push = обновление у всех). Сервер: `~/mc-nightshift-server`
(tmux -L nightshift). Витрина для проверок: `~/mc-nightshift-test` (tmux -L nstest).

# «Вахта» — сборка «только механизмы» (дизайн, 28.09.2026)

Новый мир «Ночной смены». Лор: смену перебросило в чужой мир; на точке высадки — ящик вахтовика с первыми
механизмами. Дальше мир ничего не даёт даром: **руками — только собирать, всё остальное — машины Create.**
Набеги, рассудок, скримеры, квесты остаются. Ветка разработки — `vahta` (от `extras`, 2.0.14). `main` не трогать:
пуш в `main` = обновление у всех игроков.

## Решения (согласовано с Георгием)

1. **Новый мир.** Текущий мир сохраняется архивом.
2. **Нет ручного крафта.** Верстак не открывается, сетка 2×2 в инвентаре не работает, крафт-апгрейды рюкзаков и
   хранилищ (Sophisticated), Crafting Tweaks и любые «карманные верстаки» других модов — отключены.
   Все рецепты выполняют машины (в `config/create-server.toml` уже включено: `allowRegularCraftingInCrafter`,
   `allowShapelessInMixer`, `allowShapedSquareInPress`, `allowStonecuttingOnSaw`).
3. **Куда переезжают рецепты верстака (итог, 28.09):**
   - бесформенные — миксер (Create делает это сам);
   - квадратное сжатие 2×2/3×3 одного предмета — пресс (Create делает сам);
   - формы из дерева и камня (ступеньки, плиты, стены, заборы, калитки, двери, люки, кнопки, нажимные плиты) —
     пила с фильтром (`create:cutting`);
   - **все остальные фигурные (где важен порядок) и крупнее 3×3 — механические крафтеры** (основной путь;
     в миксер фигурные не переводим — у многих совпадает набор: кирка/топор, дверь/ступеньки/люк).
4. **Печь руду не плавит** (обычная, доменная, коптильня — еда/стекло/уголь можно). Руда → дробление → промывка →
   плавка вентилятором Create.
5. **Доски — только пилой** (6 шт. с бревна), палки — пилой по доскам.
6. **Всё добывается на базе, шахта — бонус.** Каждая руда — своя «прикольная» цепочка машин (идеи из любимой
   сборки Георгия «Create 2 Mekanism Sky Edition 2», разбор — отдельно), тиры ускорения через компрессию ×9/×81.
   Шахта даёт больше с блока и редкости; сито — не основной источник.
7. **Стол трансмутаций (ProjectE) — почти сразу**: после первых машин (андезитовый сплав). Философский камень
   убран; руды по EMC дорогие (машинная линия выгоднее), строительные блоки дешёвые.
8. **Ящик вахтовика** — в работе (минимум: сетка механических крафтеров 3×3 + привод + немного сплава;
   точный состав — после подсчёта рецептов).

## Данные для анализа

- `tools/data/recipes-dump.json.gz` — все рецепты из jar серверных модов + ванилла + `kubejs/data`:
  `{ "ns:path": { "src": "<jar>", "json": <рецепт как в data/> } }` (23 014 шт.).
- `tools/data/item-tags-dump.json.gz` — теги предметов `{ "ns:tag": [значения...] }` (объединение по всем jar;
  значения могут быть ссылками `#ns:tag` — раскрывать рекурсивно).
- Изменения рецептов в рантайме — `kubejs/server_scripts/**` (удаления/добавления по id).
- Версии: NeoForge 1.21.1, KubeJS 2101.7.2 (Rhino: только `var`, без повторных объявлений между файлами),
  KubeJS Create 2101.3.x, Create 6.0.x. Проверенные приёмы Rhino — `docs/`/комментарии в `kubejs/`.

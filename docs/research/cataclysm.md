### Общие механики, важные для обороны

- **Регенерация `nature_heal` = 25 HP/с, когда у босса нет цели.** Её гасят на 10 с только удары
  игрока и мобов (`player_attack`, `mob_attack`, в том числе големы). Урон турелей Create Big
  Cannons, скорее всего, не гасит. Босс идёт к алтарю без цели и лечится по 25 HP/с, а капы дают
  турелям снять не больше 13–20 HP/с. **Турелями такого не убить**, поэтому нужен `nature_heal = 0`
  (раздел 5). У Предвестника вдобавок `harbinger_auto_heal = 2` HP/с всегда.
- **Капы урона.** Мощные пушки упираются в потолок 20–25 за выстрел и 13–20 в секунду. Лучники
  дальше 12–18 блоков наносят меньше урона, дальше ×1,5 — ноль. Дальность считается от
  «виновника» урона. У снаряда турели, похоже, виновника нет, и тогда ограничение по дальности не
  действует (**проверить**).
- **Големы** бьют Стража Края и Незеритовое чудовище **вполовину** (прямая проверка `AbstractGolem`).
- **Эффекты.** На боссов действуют только эффекты из тега `cataclysm:effective_for_bosses`:
  скорость, сила, сопротивление, регенерация и т. п. Наши баффы Великой орды проходят.
- **Не исчезают** (`removeWhenFarAway = false`), в порталы не ходят.
- **Возврат «домой».** Возвращаются через `return_home` = 20 с без цели, но только если задан
  HomePos. Через /summon HomePos не задаётся, значит возврата нет. Надгробие и возрождатель на
  месте смерти тоже ставятся только при HomePos, то есть у нас их не будет.
- **/summon с NBT не вызывает `finalizeSpawn`**: у нас NBT есть всегда (`Tags`). Поэтому флаги
  пробуждения из таблицы обязательны, они уже прописаны в заготовке.
- **ИИ после /summon.** Наземные с проснувшимся ИИ сразу ищут цель в радиусе `follow_range` (50–70);
  без цели ими управляет наша навигация к алтарю (`moveTo`). Огромные хитбоксы застрянут в
  коридорах-ловушках, и начнётся наше «грызение». Летающих (Предвестник, отчасти Маледиктус)
  наземный путь до алтаря может не довести: **проверить** провал «моб у алтаря».

## 3. Разрушение блоков: как выключить

Два механизма. Первый — ключ **`ignore_mobgriefing`**. По умолчанию он `true` у Реликта,
Стража Края, Предвестника, Игниса, Левиафана, Маледиктуса, Чудовища и Сциллы. У Реликта, Стража,
Левиафана, Маледиктуса и Чудовища тогда разрушение корпусом идёт **без оглядки на gamerule
`mobGriefing`**. У Игниса флаг касается только треснувших кирпичей, у Предвестника — только огня
от лазера, у Сциллы не влияет ни на что: корпусом они ломают по gamerule. При `false` мод спрашивает `EventHooks.canEntityGrief`,
то есть событие NeoForge `EntityMobGriefingEvent`.
Второй — теги `cataclysm:*_immune` (`ignis_immune`, `harbinger_immune`, `remnant_immune` и т. д.):
блоки из них не ломаются никогда.

Чего конфиг и gamerule **не** закрывают:

| Что | Где | Чем закрыть |
|---|---|---|
| Огонь от взрывов Игниса (шары, удары, огненные столбы) | `IgnisExplosion`, `fire=true` | событие `ExplosionEvent.Detonate`: очистить `getAffectedBlocks()` (Игнис кладёт в этот список точки для огня) |
| Лава-бомбы Незеритового чудовища ставят источник лавы | `Lava_Bomb_Entity` | конфиг `lava_bomb_duration = 1`, `lava_bomb_random_duration = 1`: лава исчезает через 1–2 тика |
| Гроза от Сциллы (молнии поджигают) | `Scylla.WeatherChange` | `weather_change = false` |

**Рекомендация: gamerule `mobGriefing` не трогать.** Он глобальный: заденет Enhanced Hordes,
жителей, эндерменов. Вместо него — конфиг из раздела 5 и серверный скрипт на `NativeEvents`
(в паке так уже работает `hud/10_recipe_pins.js`). Сигнатуры сверены с jar NeoForge 21.1.251:

```js
// kubejs/server_scripts/raids/06_cataclysm_safety.js — ПРЕДЛОЖЕНИЕ, в ветку не добавлено
var NS_CM_GRIEF = Java.loadClass('net.neoforged.neoforge.event.entity.EntityMobGriefingEvent')
var NS_CM_DETONATE = Java.loadClass('net.neoforged.neoforge.event.level.ExplosionEvent$Detonate')
var NS_CM_DESTROY = Java.loadClass('net.neoforged.neoforge.event.entity.living.LivingDestroyBlockEvent')
var NS_CM_TYPES = Java.loadClass('net.minecraft.world.entity.EntityType')
function nsCmEntity(e) {
	try { return e != null && String(NS_CM_TYPES.getKey(e.getType()).getNamespace()) === 'cataclysm' } catch (x) { return false }
}
// Мобы и снаряды мода не ломают блоки (при ignore_mobgriefing = false мод спрашивает это событие)
NativeEvents.onEvent(NS_CM_GRIEF, function (event) {
	if (nsCmEntity(event.getEntity())) event.setCanGrief(false)
})
// Взрывы мода (Игнис) без огня и без блоков
NativeEvents.onEvent(NS_CM_DETONATE, function (event) {
	var ex = event.getExplosion()
	if (nsCmEntity(ex.getDirectSourceEntity()) || nsCmEntity(ex.getIndirectSourceEntity())) event.getAffectedBlocks().clear()
})
// Страховка: разрушение блоков живой сущностью мода отменяем
NativeEvents.onEvent(NS_CM_DESTROY, function (event) {
	if (nsCmEntity(event.getEntity())) event.setCanceled(true)
})
```

Запасной вариант без событий: в `ServerEvents.tags('block')` добавить все блоки с блок-сущностью
во все `cataclysm:*_immune` (как `sanity/30_hordes_safety.js` делает для `forge:horde_unbreakable`).
Это защитит машины, но стены всё равно будут ломаться.

## 5. Конфиг `config/cataclysm-common.toml` (серверный)

Файл появится при первом запуске. Ниже только ключи, которые меняем; NeoForge дополнит остальные
значениями по умолчанию. Пути сверены с `CommonConfig`: секция `mobs`, внутри — босс.

```toml
# для каждого босса: ignis, netherite_monstrosity, ender_guardian, ender_golem, the_harbinger→"harbinger",
# ancient_remnant, maledictus, scylla, clawdian, kobolediator, leviathan
[mobs.ignis.ignore_mobgriefing_config]
	ignore_mobgriefing = false
[mobs.ignis.nature_heal_config]
	nature_heal = 0.0            # без этого турелями не добить (25 HP/с без цели)
[mobs.ignis.cap_config]
	range_cap = 48.0             # чтобы лучники с башен дамажили; damage/dps cap — не трогаем (или ×1,5)

[mobs.netherite_monstrosity]
	lava_bomb_duration = 1
	lava_bomb_random_duration = 1
[mobs.scylla]
	weather_change = false
[mobs.harbinger]
	harbinger_auto_heal = 0.0
```

Секции для каждого босса: `ignore_mobgriefing_config` есть у ancient_remnant, clawdian, ender_golem,
ender_guardian, harbinger, ignis, kobolediator, leviathan, maledictus, netherite_monstrosity, scylla;
`nature_heal_config` — у тех же (кроме kobolediator) и у aptrgangr. Точные имена секций (`harbinger`,
а не `the_harbinger`) — по `builder.push(...)` в `CommonConfig`.
Природные спавны мода (дипплинги, кобольды, берсерки, крабы) — `[mobs.spawning]`, `*_spawn_weight = 0`,
если не нужны. Структуры мода (цитадель, арена Игниса и т. п.) появятся в новых чанках.

Клиент (`cataclysm-client.toml`): музыка боссов, громкость, свои боссбары, тряска экрана,
совместимость с шейдерами (`shadersCompat`). По умолчанию всё включено.

## 7. Ротация для волн 70–100 и «Бесконечности»

Команда — 2–3 игрока с турелями CBC, големами и куполом.

**Выключить:** Левиафан (вне воды неуязвим, набег не закончится), Коралссус и свиту.
Остальное подключать по одному, начиная со Стража Края: это самый «безопасный» крупный босс.

При подключении в `40_nightshift_raid.js` сделать:
1. С 70-й волны `boss`/`bossCount` брать из `NSG.nsCataclysmBossForWave(d)` вместо Всадника.
2. Поддержать `extra`: второй вид на волнах-вехах 80/90/100.
3. `scale.hp` для боссов Cataclysm ограничить `hpScaleMax`: сейчас на 100-й волне это ×4,1, при капе
   20 HP/с Чудовище жило бы ≥ 2 мин.
4. В `NIGHTSHIFT_MOB_HP` добавить HP из таблиц выше (для прогноза).
5. `NIGHTSHIFT_PROTECTED_NAMESPACES` не менять.

## 8. Проверить в игре

1. `/summon cataclysm:ignis ~ ~ ~ {Tags:["nightshift_raid"],PersistenceRequired:1b}` посреди тестовой
   базы при конфиге из раздела 5 и скрипте из раздела 3: не ломает, не поджигает, идёт к алтарю.
2. То же для каждого босса с флагом пробуждения; без флага — убедиться, что спит и неуязвим (так и
   проверяется вывод про finalizeSpawn).
3. Урон турели CBC по боссу: падает ли HP при `nature_heal = 0` и работает ли дальность (range cap).
4. Предвестник и Маледиктус: долетают ли до алтаря; не засчитывается ли провал раньше времени.
5. Музыка и боссбары при двух боссах сразу, плюс наш боссбар волны.
6. FPS с шейдерами (Iris) при Чудовище и Игнисе (много частиц).

## 9. Итог для решения

Мод подходит, если выполнены три условия: (1) конфиг: `ignore_mobgriefing=false`, `nature_heal=0`,
лава и погода выключены; (2) скрипт на трёх событиях NeoForge против разрушения и огня; (3) HP боссов
не раздувается Кошмаром. Иначе боссы либо сносят базу, либо неубиваемы турелями.

## 10. packwiz

Сделано (`packwiz` собран из исходников, `go install github.com/packwiz/packwiz@latest`):

```sh
packwiz modrinth add --project-id 46KJle7n --version-id PsPYpoCC -y   # тянет и Lionfish-API 3.1
# (packwiz сам обновил index.toml и pack.toml; заодно освежил два устаревших хеша vahta/*.js)
```

Убрать: `packwiz remove l_enders-cataclysm && packwiz remove lionfish-api`.
Внимание: `tools/sync.py` раскладывает все `mods/*.pw.toml`, так что мод поставится при синхронизации
из этой ветки. Без конфига из раздела 5 боссы в структурах мира ломают блоки как обычно.

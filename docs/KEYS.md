# Раскладка смены v1

Одна на всех: аддон ставит её каждому один раз на версию (строка в чате при входе), «Сброс» в «Управлении» возвращает к ней, `/nskeys apply` — поставить заново, `/smena keys` — список в игре. Источник — `tools/keys_scheme.py`.

Правила: **всегда** — у каждого действия своя клавиша; **в руке** — у разных вещей клавиши могут совпадать (в руке одна вещь); у палочек занятые буквы — с Ctrl; **Backspace — выйти** (самолёт, броня, пульт); редкое — цифровой блок.

## Смена

| Клавиша | Что делает |
|---|---|
| L | книга квестов; Alt + L — трекер квестов |
| J | планшет инженера; Shift + J — панель целей |
| ' (Э) | ранец снабжения |
| B | рюкзак; Alt + B — рюкзак ↔ сундук, на который смотришь |
| Alt + 1 / Alt + 2 | рюкзак: улучшение в слоте 1 / 2 вкл/выкл |
| K | стол трансмутации (ProjectE, если надет) |
| ` (Ё) | Ultimine — зажать и копать; ↑ / ↓ — форма |
| C | зум (как в OptiFine) |
| Alt + G / Alt + H | склад Create с собой / настройки сети |
| Alt + U | история смертей (где лежат вещи) |

## Карта и связь

| Клавиша | Что делает |
|---|---|
| M | карта мира |
| U | список меток |
| N | новая метка |
| Num + | быстрая метка там, где стоишь |
| Z | мини-карта крупно |
| Мышь 5 | метка команде; зажать — колесо меток |
| Мышь 4 | рация: говорить (зажать) |
| Alt + V / Alt + M / Alt + N | голосовой чат: меню / микрофон / выключить совсем |

## Дракон, магия, джетпак

| Клавиша | Что делает |
|---|---|
| V | позвать дракона; Shift + V — команды дракону |
| Y | колесо заклинаний (зажать) |
| H | применить заклинание |
| G | джетпак: двигатель; Shift + G — зависание |
| F4 | оружие: подсказки клавиш |

## Броня и редкое — цифровой блок

| Клавиша | Что делает |
|---|---|
| Num 6 / 7 / 8 / 9 | броня Cataclysm: способность / шлем / нагрудник / ботинки |
| Num / и Num * | броня ProjectE: шлем / ботинки |
| Num − | шлем-реактор (Guardian Beam) |
| Num , | призвать незеритового голема |
| Num Enter | сила ArPhEx |
| Alt + T | навигатор поездов: настройки маршрута |
| Alt + ; (Ж) | орган: настройка MIDI |

## Как в модах

| Клавиша | Что делает |
|---|---|
| Left Alt / Ctrl / Shift | модификаторы Create и меню рельсов, копикатов, ручных пил — как в модах |
| O / Alt + K | шейдеры: список / вкл-выкл |
| Num 0–5 | Jade: настройки, подсказки, рецепты |
| [ / ] в окне рюкзака | переложить в рюкзак / в инвентарь; колёсико — сортировка |
| R / U в окнах | JEI: рецепт / применения; P / Shift + P — закрепить / цель смены |

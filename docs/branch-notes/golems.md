# Ветка feat/golems-planet — големы только через Create + планетные металлы

База: `next` (0bbf332). В `next`/`main` не влито.

## Что выяснено (jar modulargolems 3.1.43, creategolemsgalore 0.2.1)
- **Верстак големов — не сборка, а хаб**: `TableBlock` открывает меню с вкладками `TableTabType`: CraftingMenu, StonecutterMenu, AnvilMenu, SmithingMenu, GrindstoneMenu + «улучшения» + «разборка». Плюс предмет в теге `l2menustacker:quick_access_vanilla` открывается прямо из инвентаря. Разрешённый верстак = полный обход «ручного крафта».
- Сама сборка голема к верстаку не привязана: `golem_assemble` / `golem_replace_part` — `AbstractShapedRecipe` на `CraftingInput`, тип `crafting` (проверено на витрине: `RecipeType` = crafting) → берёт механический крафтер. Шаблон -> голая часть — stonecutting (механическая пила, `allowStonecuttingOnSaw = true`). Часть с материалом — `create:sequenced_assembly` (в моде есть для латуни/цинка/незерита/...). Улучшения/снаряжение/карты — деплоер (мод сам слушает `DeployerRecipeSearchEvent`).
- Create Golems Galore = только андезитовый голем (паттерн «блок андезитового сплава + шляпа»). Шляпы делаются прессом Create — **но оба рецепта пресса в jar сломаны под Create 6.0.10** (`results: [{"item":{"id":..}}]`, в логе «Failed to parse recipe»): шляпы были недоступны вообще. Заменены рабочими копиями.
- Потеря от закрытия стола: вкладка «разборка голема на части» и smithing-рецепт `golem_add_slot` (расширение слота шаблоном). Слот-расширители (`*_expansion_template` — `IUpgradeItem`) деплоер накладывает как обычное улучшение (`appendUpgrade`), без проверки «материал-добавка».

## Решение
Верстак големов **убран из `NS_VAHTA_BENCH_ALLOW`** (теперь блок закрывается как остальные верстаки), рецепт удалён, предмет изымается из инвентарей выживальщиков (`clear` раз в 40 тиков), ПКМ предметом отменён. Тупика нет: путь шаблон -> пила -> сборочная линия -> крафтер -> деплоер полностью на машинах.

## Не проверено
- Текстуры и названия материалов видны только на клиенте (перекраска смотрелась на монтаже, но в игре не запускалось; в исходнике железа есть мох — остаётся тёмными пятнами).
- Живой прогон на ленте: пила по фильтру, деплоер+пресс на линии сборки, механический крафтер в форме 3×2 / 1×3 (проверена только логика рецепта).
- Деплоер с улучшением/шаблоном-расширителем на держателе (по коду есть, вживую нет).
- `clear` каждые 40 тиков на основном сервере: игроки с уже выданным верстаком потеряют предмет (сообщения нет).
- Баланс: цифры прикидочные.

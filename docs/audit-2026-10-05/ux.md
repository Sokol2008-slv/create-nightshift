# «Ночная смена»: удобство (QoL) — аудит и готовые решения

05.10.2026. Только чтение: пак, клиент владельца (файлы), логи сервера, Modrinth и CurseForge. В паке, на серверах
и в git ничего не менял, клиент не запускал.

Что смотрел:
- клиент владельца (`instances/CreateNightshift/.minecraft`): `options.txt` (341 клавиша), `config/`, все логи
  клиента за 25.09–05.10 (21 сессия, **1 991 строка чата**);
- сервер: `logs/*.log.gz` + `latest.log` (315 тыс. строк), `ops.json`, `nightshift_ideas.json`;
- пак: `kubejs/` (client_scripts и hud/), `index.toml`, `options.txt`, моды (сканировал jar на плагины JEI и EMI);
- аддон `axiomativ-industries` (окна «Пульт алтаря» и «Фактория»).

Почему чат считал по клиенту: в лог сервера попадают только рассылки всем (`server.tell`). Личные `player.tell`,
меню алтаря и вывод команд там не видны. Клиент владельца пишет в лог всё, что ему пришло (`[CHAT]`).

## 0. Коротко

1. **Клавиши.** На Z, V и R висит по 6–13 действий. Хуже всего глобальные пары, которые срабатывают всегда:
   F5 (вид + **перезагрузка шейдеров Iris** — в чате 6 раз «Шейдеры перезагружены»), M (карта Xaero +
   **выключение микрофона**), B (рюкзак + новая метка Xaero), U (метки Xaero + история смертей), K (шейдеры
   вкл/выкл + Kubedex + планшет ProjectE), V (меню голосового чата + ещё 10 действий). Раскладка — в п. 1.3.
   Раздавать её через мод Default Options (Balm уже стоит). `options.txt` пака **не трогать**: в `index.toml`
   у него нет `preserve`, и любая правка перезапишет игрокам все настройки.
2. **Чат.** Сами игроки написали 37 строк из 1 991 (2 %) — общаются голосом. Остальное системное:
   меню алтаря в чате — 442 строки, 22 % (с 04.10 вместо него окно, в логах 05.10 этих строк уже нет);
   эхо чужих админ-команд — 248, 12 % (все трое OP, отсюда и спойлеры хоррора: «Воспроизведён звук
   warden.heartbeat игроку Elikpro666»); достижения — 205, 10 %. Две гамрулы снимают ~23 %, остальное —
   в HUD или тосты (п. 2).
3. **Готового мода, который сделает «Планшет инженера» целиком, нет.** Ближе всех
   **JEI Crafting Tree** (`jeict` 1.0.0, MIT, исходники открыты, NeoForge 1.21.1, работает поверх JEI).
   Он строит дерево из любых рецептов JEI, включая машины Create, учитывает инвентарь, а закреплённую панель
   «материалы: есть / надо / не хватает» показывает прямо в мире. Минусы: вышел 02.10, 0 звёзд, интерфейс
   на английском и китайском, внутри AE2-логика и миксин в закладки JEI, про «Вахту» ничего не знает.
4. **Переходить на EMI не советую.** У 61 мода в паке плагин JEI, у EMI — только у 13. Create и около 30
   аддонов будут жить через прослойку (JEMI или TMRV). KubeJS-подсказки переедут без правок, а вот
   `nightshift_pin_key.js` придётся переписать. Владелец потеряет 119 + 15 закладок JEI. Взамен — дерево
   рецептов, которое всё равно видно только в окне инвентаря. Цена — 1–2 дня и риск, выигрыш маленький.
5. **Рекомендация:** сначала быстрые победы без кода (гамрулы, клавиши, Ping Wheel). Потом один вечер
   погонять `jeict` на тестовом клиенте как эталон. Затем делать свой «Планшет инженера» в аддоне.
   Механику брать как в `jeict` (MIT): дерево через API JEI + слой HUD. Своё сверху: знание «Вахты» (какая
   машина и раскладка механического крафтера), общий для команды список с сервера, русский интерфейс,
   подсветка текущего шага. MVP — 1–2 рабочих дня.
6. Обе идеи из `/idea` ложатся в тот же Планшет:
   - №1 «меню алтаря как верстак» — окно «Пульт алтаря» уже есть с 0.5.0. Стоит уточнить у автора, чего в нём
     не хватило.
   - №2 «инструмент для поиска залежей» — вкладка «Месторождения» и метки целей на HUD (п. 4.4).

### 1.3 Предлагаемая раскладка

Принцип: всё, что срабатывает всегда, — на своей клавише. Ситуативные действия (оружие, жезл, техника,
конкретный предмет в руке) могут делить клавишу, если не бывают активны одновременно. Редкие тумблеры
уезжают на Alt + буква (не WASD), способности снаряжения — на Alt + цифра.

| Действие | Сейчас | Предлагаю |
|---|---|---|
| Iris: перезагрузить шейдеры | F5 | **не назначать** |
| Iris: шейдеры вкл/выкл | K | **Alt+K** |
| KubeJS: Kubedex (админский) | K | **не назначать** |
| Голосовой чат: меню | V | **Alt+V** |
| Голосовой чат: микрофон | M | **Alt+M** |
| Голосовой чат: выключить | N | **Alt+N** |
| Голосовой чат: группы / скрыть значки | G / H | **не назначать** (есть в меню Alt+V) |
| Голосовой чат: говорить | мышь 4 | оставить |
| Curios: окно | G | **не назначать** (кнопка в инвентаре) |
| Портативный стокер (Mobile Packages) | G | **Alt+G** (на G остаётся джетпак) |
| Xaero: новая метка | B | **Alt+B** (мгновенная метка остаётся на Num +; B — рюкзак) |
| Xaero: увеличить миникарту | Z | **не назначать** (Z — только зум) |
| Xaero: настройки миникарты | Y | **не назначать** (есть «]») |
| Corpse: история смертей | U | **Alt+U** (U — список меток) |
| Cataclysm: шлем / нагрудник / способность / ботинки | C / Y / V / V | **Alt+1 / Alt+2 / Alt+3 / Alt+4** |
| DMR: призвать дракона | V | **Alt+5** |
| Iron's: колесо заклинаний | R | оставить R; если кто-то одновременно и стрелок, и маг — **Alt+R** |
| Книга квестов FTB | — | **L** |
| Ванильные достижения | L | **не назначать** |
| FTB: переключить закреплённый квест | — | **Alt+L** |
| Jade: «что делает блок» (применения) | Num 4 | **J** (J ещё у палитры жезлов — только с жезлом в руке) |
| Jade: рецепты блока | Num 3 | **Alt+J** |
| Placebo: крылья / следы (косметика) | Num 8 / Num 9 | **не назначать** |
| Ping Wheel (если ставим, п. 3.3) | — | **мышь 5** (свободна) |
| Пин рецепта в окнах | P (зашит в KubeJS) | P, но как обычная клавиша Планшета (видна в «Управлении», переназначается) |

Остаются ситуативные перекрытия на R, V, C, X, Z (оружие NTGL, жезлы, ProjectE, TFMG). Они срабатывают
только с нужным предметом в руке — это терпимо. Проверка после правок — Controlling, фильтр «Конфликты».

Как раздать игрокам:
- **Default Options** (`default-options` 21.1.8+neoforge-1.21.1, нужен Balm — уже в паке). Владелец
  настраивает у себя и выполняет `/defaultoptions saveKeys`, в пак уходит
  `config/defaultoptions/keybindings.txt`. Раскладка становится новыми умолчаниями: у новых игроков сразу,
  у старых — по кнопке «Сбросить всё» в «Управлении». Пользовательские правки при обновлениях не слетают.
- **Не править `options.txt` пака.** Он в `index.toml` без `preserve = true`, а в нём всего 4 строки
  (`lang`, дальность, масштаб). Если изменить файл, packwiz-installer при обновлении перезапишет игрокам
  весь `options.txt`, и все клавиши и настройки сбросятся.
- Запасной вариант без мода: одноразовая миграция в аддоне (на старте клиента, по флаг-файлу,
  `KeyMapping#setKey` + `KeyMapping.resetMapping()` + `options.save()`).
- Альтернатива раскладке — KeybindsGalore (HVB007): на спорной клавише всплывает круговое меню выбора.
  Для боя это неудобно, и сам мод сидит на K. Раскладка лучше.

### 2.2 Быстрые правки (без нового кода или почти)
1. `/gamerule logAdminCommands false`: −12 % и без спойлеров. Свои команды (`sendCommandFeedback`)
   продолжают отвечать.
2. `/gamerule announceAdvancements false`: −10 %.
3. `sendMessages = false` у Simple Backups (пак + сервер).
4. Клиентский фильтр в `kubejs/client_scripts/`: 10 строк, `NativeEvents.onEvent` на
   `net.neoforged.neoforge.client.event.ClientChatReceivedEvent$System`, `setCanceled(true)` для строк с
   «Create Train Utilities», «will be renamed Create Train Doors», «/obsessed debugmode»,
   «Spawnrate configurations». Тот же приём, что в `nightshift_pin_key.js`.
5. `[Рецепт] X закрепил: …` уходит всем в чат (`server.tell`). Заменить на actionbar или тост; в Планшете —
   строка в самой панели.

### 2.3 Что перенести в HUD или тосты (через аддон)
В аддоне уже есть канал «сервер → клиент» (пакет «Пульта алтаря», `AltarMenu.pack/unpack`). Добавить один
общий пакет «уведомление» (`kind`, иконка-предмет, заголовок, строка, цвет, время) и на клиенте показывать
его своим тостом. Из KubeJS вызывать как `nsAltarScreenSend`. Кандидаты:
- «Идёт набег — алтарь занят» (17), «Блок базы ставится только в зоне» (13), «Пока проклятие не искуплено…» —
  строка над хотбаром (`setStatusMessage`), не чат;
- «Добыча: …», «X получает артефакт», «Контракт выполнен», «Веха…» — тост с иконкой предмета;

cloth-config, kotlin-for-forge и architectury в паке уже есть) — вкладки чата по регулярке, например
«Смена» для `^\[(Ночная смена|Фактории|Метеорит|Жилы|Сканер)\]`.

## 4. Рекомендация: свой «Планшет инженера» в аддоне, `jeict` — как эталон

### 4.1 Почему не взять готовое целиком
- Ни один мод не знает правил «Вахты»: ручного крафта нет, бесформенные рецепты и 2 785 «фигурных» делает
  миксер, остальное — механический крафтер, которому нужна **раскладка**. Игрокам нужен ответ «на какой
  машине и как», а не «какие ингредиенты».
- Нужен **общий для команды** список (как сейчас `/pin` через скорборд), а готовые моды — клиентские и
  личные.
- Русский интерфейс; у `jeict` только en и zh.
- Зрелость: `jeict` — 3 дня от роду, один автор, миксин в JEI. JECT закрыт (ARR). EMI-решения тянут смену
  просмотрщика.
- Свой код легко связать с системами пака: фактории (что везти), форпосты и месторождения (идея №2),
  метеорит, набег.

### 4.2 Что взять за основу (всё доступно на NeoForge 1.21.1, JEI 19.57)
- **Источник рецептов — API JEI на клиенте**, а не `RecipeManager` сервера. Это сразу даёт все категории
  Create и аддонов, рецепты KubeJS, скрытие по стадиям (AStages) и ровно то, что игрок видит в JEI. Тот же
  подход, что у `jeict`.
  - В аддоне — `@JeiPlugin` (`compileOnly` на `mezz.jei:jei-1.21.1-neoforge-api`), `IJeiRuntime` из
    `onRuntimeAvailable`.
  - Рецепты предмета: `IRecipeManager.createRecipeLookup(type).limitFocus(focusFactory.createFocus(
    RecipeIngredientRole.OUTPUT, VanillaTypes.ITEM_STACK, stack))` по категориям.
  - Входы и выходы: `IRecipeManager.createRecipeLayoutDrawable(...)` → `IRecipeSlotsView` (слоты с ролями
    INPUT, OUTPUT, CATALYST).
  - Машина шага — катализаторы категории: `IRecipeManager.createRecipeCatalystLookup(type)`, это и есть
    «миксер», «пресс», «деплоер».
  - Мини-рецепт на панели: `IRecipeLayoutDrawable#drawRecipe` — родная картинка JEI, в отличие от Pin It.
  - «Что под мышью» в окнах — как сейчас в `nightshift_pin_key.js`: `getIngredientListOverlay`,
    `getBookmarkOverlay`, `getRecipesGui().getIngredientUnderMouse`.
  - Кнопка у рецепта: «Вахта» блокирует ручной крафт, и кнопка «+» (перенос рецепта) свободна. Через
    `IRecipeTransferRegistration#addUniversalRecipeTransferHandler` её можно сделать кнопкой «закрепить»
    для любого рецепта в окне инвентаря. **Проверить**, что метод есть в API 19.57 и как поведёт себя
    подсказка «+».
- **Точный счёт там, где JEI показывает картинку, а не количество** — прямо по классам Create (аддон и так
  собирается против Create 6.0.10):
  - `SequencedAssemblyRecipe#getLoops()` и `getSequence()` — ингредиенты шагов × повторы. Механизм точности:
    5 повторов, а в раскладке JEI каждый ингредиент нарисован один раз;
  - `ProcessingRecipe#getRequiredHeat()` — нужен ли «нагрев» или «перегрев» (горелка);
  - шансовые выходы (`ProcessingOutput#getChance`) — показывать «~80 %» и закладывать запас;
  - `MechanicalCraftingRecipe` / `ShapedRecipe` — сетка для раскладки на механических крафтерах.
- **Отрисовка** — свой слой HUD через `RegisterGuiLayersEvent` (не скорборд): справа, место и размер
  настраиваются, не перекрывать миникарту Xaero.
- **Сеть** — как у «Пульта алтаря»: пакет «список команды» (сервер хранит закрепы в `persistentData`, как
  сейчас `nightshift_pins`), клиент считает дерево сам. KubeJS-команды `/pin` и `/unpin` остаются: вместо
  скорборда шлют пакет.
- **Из `jeict` (MIT) подсмотреть** разбор раскладок JEI в дерево, обработку циклов («блок ↔ слитки»),
  выбор альтернатив, «плавающую» панель на `RenderGuiEvent.Post`. При копировании кода — сохранить
  уведомление MIT.

### 4.3 Объём MVP
1. Клавиша «закрепить» (P, переназначаемая, `KeyConflictContext.GUI`) над предметом в JEI, инвентаре или
   закладках; «+1» повторным нажатием; Shift — ×10.
2. Панель на HUD: цель × N → шаги снизу вверх; у каждого шага — иконка машины и «есть / надо» по
   инвентарю (плюс открытый контейнер; рюкзак — позже). Цвета: зелёный — хватает, жёлтый — можно сделать
   сейчас, красный — не хватает сырья. **Текущий шаг пульсирует** — это та самая «светится».
3. Правила «Вахты»: бесформенный рецепт → «миксер»; фигурный → «механический крафтер» + мини-сетка
   раскладки; машинные — их катализатор.
4. Остановка разбора на сырье: теги `c:ingots`, `c:gems`, `c:dusts`, `c:raw_materials`, брёвна, камень —
   как `PIN_STOP_TAGS` в `10_recipe_pins.js`. Выбор предмета из тега — как `pinRank`.
5. Общий список для команды с сервера + личный режим.
6. Русский язык, тумблер панели (клавиша), компактный и полный вид.

Подводные камни: повторы сборки по шагам; шансовые выходы; жидкости в мБ; несколько рецептов на один
предмет (по умолчанию — приоритет «Вахты», клик — переключить); циклы; скрытые по фазам рецепты (брать то,
что видно в JEI); кэш дерева (не пересчитывать каждый кадр, пересчёт по изменению инвентаря); ширина панели
при длинных русских названиях.

Оценка: MVP — 1–2 рабочих дня. Второй заход — ещё 1–2: окно-«планшет» с поиском, вкладки, «что делает
машина», метки целей, тосты.

### 4.4 Второй заход: мини-фишки
- **«Что делает эта машина»**. Смотришь на блок и жмёшь клавишу → список категорий, где блок — катализатор
  («Миксер: смешивание 214, автокрафт 1 960, нагрев…»), клик открывает JEI на категории
  (`IRecipesGui.showTypes`). Пока Планшета нет, то же самое уже умеет Jade «применения» — нужно только
  переназначить с Num 4 на J. Shift+ПКМ по машине для этого не советую: у Create на Shift+ПКМ свои действия
  (снять фильтр и т.п.).
- **Метки целей на HUD** (идея №2 «залежи»). Сервер шлёт список целей: форпосты, месторождения, метеорит,
  фактория с активным заказом, точка орды. Клиент рисует маркер с названием и расстоянием по краю экрана и
  в мире, как Ping Wheel. Плюс кнопка «в Xaero» — временная метка через рефлексию, так делает Ping to Map
  Xaero. Убирает 13 кликов `[Add]` и часть `/tp`.
- **Вкладка «Месторождения»**: результаты детектора и сканера жил, форпосты, геотермальные источники и
  пороги (энергофорпосты 0.6.0) — список с направлением и дистанцией вместо 5 строк чата на каждое ПКМ.
- **Тосты пака** — один пакет «уведомление» (п. 2.3): фактории, добыча, артефакты, контракты, метеорит.
- **Подсветка машины в мире**: для текущего шага найти ближайший миксер, пресс или крафтер в загруженных
  чанках и обвести контуром.
- **Связка с Sophisticated Item Actions** (если встанет): из панели «где лежит» → подсветка сундуков.

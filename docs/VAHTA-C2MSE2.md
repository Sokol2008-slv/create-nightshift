# Разбор «Create 2 Mekanism Sky Edition 2» — как там добывают ресурсы (для «Вахты»)

Любимая сборка Георгия (Forge 1.20.1, Create 6, 308 модов, skyblock). Главное: руда почти не добывается напрямую —
каждый металл берётся из «своего» камня через дробление и промывку; сито — только для камешков, цинка и самоцветов;
основа экономики — ProjectE (EMC) с первой минуты (стол трансмутации на стартовом острове).

## Ресурс → цепочка

| Ресурс | Как получают без шахты |
|---|---|
| Булыжник/камень | генератор булыжника; сжатый блок под ним задаёт породу (уровни сжатия 1–5 → 10/25/50/75/100% андезита, диорита, гранита, энд-камня, земли душ, небесного камня, незерака) |
| Андезит, диорит, гранит, незерак, энд-камень | механический экструдер (Create Mechanical Extruder): вода + лава + неразходуемый катализатор-сжатый блок; уровень сжатия = 5→1 ударов |
| **Железо** | гравий → промывка вентилятором: 25% самородка железа + 25% кремня |
| **Медь** | гранит → жернов/дробилка → `crushed_granite` → промывка: 25% самородка меди + 25% редстоуна |
| **Цинк** | `crushed_diorite` → промывка: 25% самородка цинка + 25% кварца (или сито) |
| Кобальт | `crushed_andesite` → промывка: 25% самородка + 25% пороха |
| **Золото** | дроблёный незерак → промывка: 25% самородка золота + 25% пепельной муки |
| Уголь, редстоун, лазурит | сито (гравий/красный песок/пыль, шансы растут по уровню сетки) |
| Кварц / аметист | сито; промывка диорита; haunting аметиста → кварц |
| Кварц истинности | небесный камень в жернове → пыль → сито → семя → выращивание (4 пролива по 500 мБ воды на ступень) |
| Алмаз, изумруд | философский камень (4 золота → алмаз, 2 алмаза → изумруд); изумруд — алмаз под деплоером со звездой Незера (не тратится) |
| Эндер-жемчуг | haunting слизи → 25%; сито дроблёного энд-камня |
| Светопыль | haunting редстоуна |
| Огненный стержень | блок угля → наждачка → угольный стержень → сборка 4 цикла (лава 250 мБ ×2 + пресс) |
| Незерак, песок душ, энд-камень, слизь, глина, обсидиан | бочки Ex Deorum и «ведьмина вода» (вода на мицелии): + песок → песок душ, + лава → незерак, лава + светопыль → энд-камень, вода + молоко → слизь |
| Кожа, животные | семена животных (Haven Animal Seeds): посадил — через 10 мин моб |

## Старт

Остров 3×3 (трава + обсидиан + стол трансмутации), пустой инвентарь; камешки — присед+ПКМ по траве; награды первых
квестов крупные (по 64 камня/земли/песка, саженцы, ведро, по 8 цинка/сплава/механизмов). «Курица и яйцо» решена
ручным бесформенным рецептом первого механизма (пила изнашивается) и «корпус + деталь на кузнечном столе».
10 эпох механизмов (как Create: Above and Beyond): кинетический → запечатанный → точный → … → электрический.

## Ограничения и EMC

EMC открыт с нуля, автоподсчёт EMC для крафтов выключен (`CraftingMapper=false`): ценность есть только у первичных
ресурсов, переработанное её теряет — «цель — производить вторичные ресурсы». Дорого: цинк 128, кобальт 4096,
огненный стержень 8192, металлы Mekanism 524 288. Коллекторы/конденсаторы — поздно.

## Лучшие идеи для переноса (чистый Create + KubeJS)

1. **Свой камень — свой металл**: `crushed_<камень>` → промывка → 25% самородка + 25% побочного продукта.
2. **Генератор с катализатором-сжатым блоком**: уровень сжатия = выход/скорость (экструдер или миксер: вода + лава
   + катализатор, возвращается на выходе).
3. **Выращивание кристаллов**: семя → … → кристалл (сборка с проливами воды), камнерез 1 кристалл → 2 семени.
4. **Haunting-алхимия** (душевной костёр перед вентилятором): аметист → кварц, редстоун → светопыль,
   слизь → 25% эндер-жемчуга.
5. **Вечный инструмент в деплоере** (`keepHeldItem`): звезда Незера превращает алмаз в изумруд.
6. **Огненный стержень без Незера** — сборка из угольного стержня с лавой.
7. **Измерения как ворота прогрессии** (рамки портала из сжатых блоков).

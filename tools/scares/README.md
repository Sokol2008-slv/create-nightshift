# Скримеры — набор ведущего

В `.packwizignore`, друзьям не раздаётся. Все команды идут в консоль боевого сервера (`tmux -L nightshift`),
в чат ничего не попадает (`gamerule logAdminCommands false`, `broadcast-console-to-ops=false`).
Для проверки на витрине: `SRV=nstest ./scare.sh …`.

## Серверные (KubeJS, с 2.0.12) — `./scare.sh …` или `/scare …` в игре (только Sokol2008)

| Команда | Что происходит |
|---|---|
| `mono <ник> [режим]` | **Монохром** — чёрный силуэт ~2,8 блока с белыми светящимися глазами (по умолчанию `hunt`) |
| `clown <ник> [режим]` | **Клоун** — выглядывает из-за угла, наполовину за стеной (по умолчанию `peek`) |
| `faces <ник> [радиус 3–10] [сек 1–10]` | открытый камень, земля, доски, брёвна вокруг становятся моргающими глазами, потом возвращаются |
| `box <ник> [сек 2–15]` | коробка из глаз вокруг игрока 5×5×5 (внутри 3×3×3), машины и сундуки не трогает, внутри невидимый свет |
| `watcher <ник>` | Наблюдатель (End Watchers): высокий чёрный силуэт вдали за спиной, шепчет «I see you», исчезает, когда на него смотрят |
| `face <ник>` | фото-лицо (Horror Faces) вплотную на 1,5 с + хруст костей; впереди стена — за спиной, камера разворачивается |
| `voice <ник> [hey\|see\|behind]` | искажённый голос из-за спины |
| `dweller <ник>` | погоня Cave Dweller: своя анимация (ползёт, несётся на четвереньках), звук «заметил» и музыка погони; безвреден (атака 0); догнал (не раньше 6 с) — исчезает, секунда темноты |
| `preset <ник> [hunt\|mine\|house\|quiet]` | готовые сценарии: **hunt** — «hey» → Наблюдатель → «…беги…» → погоня → лицо; **mine** — глаза → «behind you» → клоун из-за угла → погоня; **house** — коробка из глаз → лицо внутри; **quiet** — шёпот → голос → Наблюдатель |
| `whisper <ник> <текст>` | строка над хотбаром тёмно-красным курсивом — как сообщения рассудка сборки |
| `stop` | убрать всех и вернуть блоки |

## Часть 2 (28.09, `scares/20_scares_more.js`) — тише и страшнее

| Команда | Что происходит |
|---|---|
| `flash <ник> [1–6]` | **лицо на весь экран** ~1 с + крик (Horror Faces + ArPhEx + эндермен), мир в этот миг в слепоте. Картинка — шрифт `nightshift:scare`: нужен клиент с ресурсами пака (на старых клиентах будут белые квадраты) |
| `steps <ник> [сек=40]` | **шаги за спиной**: идут по его следу с отставанием ~1,3 с (≈5 блоков), звук блока под ногами. Остановился — ещё два шага (2,2 и 1,3 блока за спиной) и тишина. Обернулся — шаги замирают на 3 с |
| `knock <ник>` | **стук** в ближайшую дверь (12 блоков): тук-тук-тук, пауза, громче; через ~10 с дверь сама открывается, через 3 с захлопывается. Нет двери — стучит в стену за спиной |
| `note <ник> [текст]` | **«Записка»** (бумага с подписью тёмно-красным) в случайный свободный слот рюкзака, не в хотбар — найдёт сам. Без текста — случайная из заготовок |
| `tunnel <ник>` | **глаз в тоннеле**: в камне за блоком, на который он смотрит, прячется глаз (неразрушаемый). Докопал и посмотрел ~1 с — сердцебиение, глаз снова становится камнем у него на глазах. Не докопал за 3 мин — тихо возвращается |
| `lights <ник> [радиус=12]` | **свет гаснет**: факелы и фонари по одному, от дальних к ближним; через 20 с загораются. «Тьма сжимается» в это время не бьёт |
| `twin <ник> [чья голова]` | **двойник**: Монохром с головой игрока (по умолчанию его самого) стоит в ~18 блоках, потом выглядывает ближе |
| `join <ник> [чей ник]`, `leave <ник> [чей ник]` | поддельное жёлтое «… присоединился/покинул игру» — видит только цель |
| `preset <ник> night` | шаги → стук → свет гаснет → двойник → лицо на весь экран |
| `preset <ник> deep` | глаз в тоннеле → шаги → клоун из-за угла → погоня → лицо на весь экран |
| `auto on\|off\|status` | **режиссёр**: сам подбрасывает скримеры каждому раз в 15–30 мин (первый — через 10–20 мин после входа; при сильном безумии до двух раз чаще). Выбирает по обстановке: под землёй — глаз в тоннеле, клоун, глаза, погоня (если один); ночью на поверхности — двойник, Наблюдатель, силуэт, стук (если рядом дверь), свет; всегда — шёпот, шаги, голос, записка; редко — лицо. Не трогает во время набега, в творческом и наблюдателе. По умолчанию **выключен**, состояние переживает рестарт |
| `auto skip <ник>` | режиссёр не трогает игрока (повтор — снова трогает) |
| `auto now <ник>` | режиссёр выбирает и запускает скример прямо сейчас (проверить, что он выберет) |

Режимы: `stalk` — стоит за спиной в ~20 блоках и смотрит, исчезает, когда увидели; `peek` — из-за угла в 4–12 блоках;
`dash` — пробегает поперёк взгляда в ~10 блоках; `chase` — погоня Cave Dweller (у хаска анимация кривая); `turn` — над хотбаром «…обернись…», обернулся — он в 2 блоках перед лицом; `hunt` — сценарий
(Монохром: стоит → пробегает → стоит ближе → погоня; Клоун: выглядывает → ещё раз → погоня).

Никто не бьёт: урон 0, бессмертны, без лута. Внешность — ETF по команде `ns_mono` / `ns_clown`
(`kubejs/assets/minecraft/optifine/random/entity/zombie/husk2.png`, `husk3.png`, глаза `*_e.png`).
Подмена блоков пишется в persistentData: упадёт сервер посреди скримера — блоки вернутся при запуске.

## Консольные (работают без рестарта)

| Скрипт | Что происходит |
|---|---|
| `lights_out.sh <ник>` | факелы и фонари вокруг гаснут по четвертям, за спиной светящаяся табличка «<ник>, я рядом», свет возвращается через 8 с |
| `lava_off.sh <ник> [радиус=32] [сек=5]` | вся лава вокруг исчезает на несколько секунд и возвращается |
| `face.sh <ник> [mono\|clown] [блоков=1.6]` | вплотную за спиной, камера разворачивается к нему, крик, секунда слепоты. В коробке — `./scare.sh box <ник> 7; sleep 3.5; ./face.sh <ник> mono 1.2` |
| `fullscreen.sh <ник>` | на весь экран лицо древнего стража (частица elder_guardian) + проклятие и крик |
| `pumpkins.sh <ник> [радиус=6] [сек=3]` | камень вокруг становится тыквами-лицами к игроку (запасной вариант `faces`) |

`lights_out`, `lava_off`, `pumpkins` на время копируют участок в небо (y 300+) и потом стирают копию —
лава из копии успевает немного протечь и сама высыхает.
